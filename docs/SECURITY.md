# Security & fair-play boundary

NekoVerse Companion is designed as a **desktop companion/accessibility utility**, not a game bot.

Allowed by design:
- One-shot user-triggered hotkeys for utility controls such as landing gear, lights, or an ATC/landing binding you configure yourself.
- Voice recognition that maps a spoken phrase to one of those explicitly configured commands.
- Reading public web data, local hardware information, and local Star Citizen settings files.
- Conservative graphics recommendations and reversible settings changes.

Not implemented:
- Aim, recoil, targeting, combat, mining, trading, navigation or movement automation.
- Repeating/unattended macro loops.
- Memory reading/injection, packet manipulation, process hooking or anti-cheat bypasses.
- RSI account/session harvesting.

If a future contribution adds automation, keep it human-triggered, one-shot, reversible, and non-competitive.
